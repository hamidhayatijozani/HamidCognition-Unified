## Consolidation decision

The HamidCognition program is now represented by one canonical GitHub repository: **HamidCognition-Unified**.

The previous repositories remain public historical records where they provide useful provenance, but the active integration point is this repository. Their code and research lineage are copied into `integrated/` where practical, while the original repositories retain their own Git history.

## What "unified" means

Unified means one canonical project tree, one provenance record, one research status model, and one current product boundary.

It does **not** mean that historically different implementations are falsely declared identical. Behavioral divergence remains visible and testable.

## Canonicalization

Only artifacts with explicit evidence may be promoted from integrated historical material into the current canonical implementation. The existence of copied source code is not evidence of semantic equivalence, correctness, or production readiness.
