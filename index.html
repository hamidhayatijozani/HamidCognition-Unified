Action Gate

A pre-execution authorization and evidence boundary for AI-agent tool calls.

Agent → Action Gate → Protected Tool

Before a privileged action reaches an HTTP or MCP tool, Action Gate evaluates the request, binds authorization to its execution context, issues execution authority, and enforces the governed path.

Product

ALLOW / DENY / ASK / SANDBOX · tenant/actor/session/action binding · cryptographic authority · single-use nonce and replay protection · HTTP/MCP enforcement · fail-closed evidence handling · PostgreSQL persistence · audit/replay evidence.
