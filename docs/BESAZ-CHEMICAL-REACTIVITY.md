# BESAZ: Chemical Reactivity Experiment

This document records a bounded innovation experiment for HamidCognition.

The experiment treats execution conditions as a reaction environment. Context, live
state, evidence and trajectory act as stability conditions; activation and inhibition
act as enabling and blocking pressures.

The implementation lives in `state_bound/chemical_reactivity.py`.

This is deliberately a sandboxed research model. It does not authorize execution and
does not claim a physical-chemistry equivalence. Its value must be demonstrated by
reproducible experiments against existing Action Gate and state-bound baselines.

Promotion path:

PROPOSED -> TESTABLE -> TESTED -> CANDIDATE -> explicit verification -> PRODUCTION

A failed experiment remains evidence and is not hidden.
