# Integrated HamidCognition Modules

This directory is the consolidated code and research lineage of the earlier HamidCognition repositories.

## Canonical status

The canonical project is the root **HamidCognition-Unified** repository. The files below are integrated source artifacts, not automatic assertions that every historical implementation is equivalent or production-ready.

## Included lines

- `ps_t/` — P/S/T engine variants from the foundational HamidCognition implementations.
- `trading/` — EUR/USD simulation and predictor lineage.
- `realtime/` — real-time market and dashboard lineage.
- `web/` — web application lineage.
- `runtime/` — earlier integrated runtime entry points and configuration.
- `legacy/v0-max/` — V0-Max implementation lineage.
- `research/epistemic-filter/` — earlier HHJ-CSG / epistemic-governance RFC and POC lineage.

## Integration rule

Source artifacts are preserved with their original behavioral identity and provenance. Exact duplicates are not silently rewritten into a new semantic implementation. Where variants differ, the Unified research record treats the difference as evidence.

The Action Gate runtime under `action_gate/` remains the current product boundary. The integrated historical modules are research and lineage assets unless separately promoted by executable evidence.
