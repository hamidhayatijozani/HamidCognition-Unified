# ClaimLab Reality Engine

ClaimLab is an executable research layer for separating what was observed from what is inferred, explained, or asserted as ontology.

It treats UNKNOWN as distinct from INVALID and records supporting, contradicting, stale, missing, and conflicted evidence. Each claim receives deterministic Claim DNA and each assessment receives an evidence fingerprint.

Research loop: Observation -> Claim -> Evidence Tension -> Counterclaim -> Falsification Test -> Verdict.

ClaimLab is not a truth oracle, causal-identification system, or commercial safety certification. A passing unit test proves implementation behavior, not scientific validity.
