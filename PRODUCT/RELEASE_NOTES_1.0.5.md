# HamidCognition Action Gate v1.0.5

## Release boundary

This release packages Action Gate as a deployable policy-enforcement boundary between an agent and protected tools.

It provides:

- authenticated action evaluation;
- tenant, actor and session binding;
- signed decision evidence;
- explicit ALLOW, DENY, ASK and SANDBOX outcomes;
- persistent execution reservation and nonce protection;
- governed HTTP/MCP enforcement paths;
- replayable evidence;
- production Compose deployment with PostgreSQL;
- clean-room and product-integrity verification.

## Commercial boundary

The supported commercial delivery modes are SELF_HOSTED, MANAGED and ENTERPRISE.

The product does not claim universal AI safety, regulatory certification, downstream correctness or guaranteed business outcomes. Customer-specific acceptance remains required before production execution is enabled.

## Payment boundary

Commercial settlement for this product is USDT only.

Payment is handled as an external commercial transaction, not as an execution capability of Action Gate. The repository contains no private wallet keys and must never receive them.

A payment record must bind:

- invoice ID;
- product/version;
- quoted USDT amount;
- accepted network;
- receiving address fingerprint;
- transaction hash;
- settlement status;
- confirmation evidence;
- delivery entitlement.

A sale is not marked paid from a screenshot or customer assertion alone. Settlement requires an independently recorded transaction hash and the configured confirmation policy.
