# HamidCognition Action Gate

## What it is
A deployable policy-enforcement boundary between an AI agent and protected tools.

## What it does
Before a protected action executes, Action Gate can:
- authenticate the caller;
- bind tenant, actor, session, and action identity;
- evaluate policy;
- issue an execution authority;
- enforce one-time nonce and expiry constraints;
- persist evidence;
- fail closed when required authorization/evidence conditions are unavailable;
- support replay and audit of recorded decisions;
- enforce HTTP and MCP integration boundaries.

## What the customer receives
A versioned runtime, deployment package, configuration template, integration contract, security boundary, operations runbook, acceptance procedure, and provenance manifest.

## What is validated
The v1.0.2 release baseline has automated CI evidence for product integrity, clean-room verification, production end-to-end smoke, repository verification, PostgreSQL persistence/replay, and release-candidate artifact generation.

## What is not promised
Action Gate does not by itself guarantee customer policy correctness, downstream tool safety, regulatory compliance, universal AI safety, or business/financial outcomes.
