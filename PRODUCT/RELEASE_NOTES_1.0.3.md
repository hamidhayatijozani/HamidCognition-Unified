# HamidCognition Action Gate v1.0.3

## Release purpose

v1.0.3 is the hardened commercial-delivery baseline following the v1.0.2 runtime validation.

## Security hardening

- Execution authority nonces are persisted in SQLite rather than process memory.
- The production Compose deployment mounts persistent tool authority state at /data.
- The tool execution boundary accepts only Gate-issued ALLOW authority.
- SANDBOX authority is rejected by the executable tool boundary.
- Release publishing write privileges are isolated into dedicated publisher workflows.
- Reachable Git history is scanned for high-confidence secret signatures without printing secret material.
- Release-candidate publication is downstream of successful Product Gates, avoiding race-prone same-SHA polling.

## Validation boundary

The release pipeline validates the tested decision, enforcement, tool, evidence, persistence, replay, clean-room, and production E2E paths. These tests do not establish universal AI safety, customer policy correctness, regulatory certification, downstream system correctness, or business outcomes.

## Distribution

The repository is private. Production secrets remain external to source control. Commercial delivery requires the separate written license/authorization defined by the product documentation.

## Provenance

The exact release artifact is generated by the Action Gate Release Candidate workflow only after successful Product Gates for the same commit and is published by the dedicated Product Release Publisher workflow.
