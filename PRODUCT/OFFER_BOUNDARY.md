# Action Gate Commercial Offer Boundary

## Product

HamidCognition Action Gate is a deployable authorization and evidence boundary between an agent and protected tools.

Core capabilities:
- authenticated action evaluation;
- tenant, actor, and session binding;
- policy snapshot and policy hash;
- signed decision records;
- one-time execution nonce;
- approval path for ASK decisions;
- production execution boundary;
- HTTP and MCP enforcement;
- fail-closed evidence persistence;
- PostgreSQL persistence;
- replay and audit evidence;
- self-audit endpoint;
- reproducible container build and CI evidence.

## Delivery packages

### SELF_HOSTED
Runtime, deployment contract, configuration template, integration contract, acceptance procedure, operations runbook, and release evidence.

### MANAGED
HamidCognition operates the service boundary. Hosting, data residency, support, monitoring, and SLA terms are negotiated separately.

### ENTERPRISE
Negotiated integration, security review, support, change-management, deployment architecture, and SLA scope.

## Explicit non-inclusions

No automatic promise of regulatory certification, universal AI safety, downstream tool correctness, HSM/KMS custody, identity-provider federation, SIEM integration, high availability, or business outcomes.

## Commercial acceptance

A customer should buy against a defined acceptance test, not a marketing claim. The baseline procedure is `PRODUCT/CUSTOMER_ACCEPTANCE.md`; customer-specific controls must be added when required.

## Pricing

Pricing is outside the engineering repository and should be set according to deployment responsibility, integration complexity, support scope, and contractual risk.
