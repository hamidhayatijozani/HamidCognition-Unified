# Commercial Pricing Framework

## Purpose
Pricing is intentionally separated from engineering validation. The figures below are a proposal framework, not market facts or promises.

## Package structure

### SELF_HOSTED
One-time deployment/license fee plus optional annual maintenance.

Scope:
- versioned Action Gate runtime;
- deployment package;
- customer acceptance support;
- standard documentation;
- defined update rights.

Commercial variables:
- number of production environments;
- integration complexity;
- deployment assistance;
- maintenance term.

### MANAGED
Recurring service fee.

Scope is negotiated around:
- hosted execution boundary;
- environment count;
- request volume/throughput;
- support level;
- data-retention requirements;
- integration scope.

### ENTERPRISE
Negotiated annual contract.

Variables:
- custom integrations;
- security review;
- dedicated environments;
- SLA;
- onboarding;
- upgrade/rollback assistance;
- additional compliance or operational requirements.

## Pricing worksheet

| Variable | Unit | Value |
|---|---|---|
| Pilot / proof-of-value | fixed / 30 days | 2,500 USDT (proposed standard offer; not market-validated) |
| Production environments | environment | scoped in order form |
| Integration work | day/project | quoted separately |
| Annual maintenance | year | UNVALIDATED; quote only in a signed order form |
| Managed service | month | UNVALIDATED HYPOTHESIS; not a current quote |
| Enterprise support | year | UNVALIDATED HYPOTHESIS; not a current quote |
| Custom security review | project | quoted separately |

## Payment

All amounts are payable in USDT only. The invoice states the network, receiving address, amount and deadline.

## Pricing rule
Do not quote a number as a technical fact. Final pricing belongs in a signed order form and should reflect delivery responsibility, integration effort, support obligations, and contractual risk.
