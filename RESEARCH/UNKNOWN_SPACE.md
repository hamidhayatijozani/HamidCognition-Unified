# Unknown Space Archive

این فایل برای چیزهایی است که هنوز نمی‌دانیم، نه چیزهایی که فقط هنوز کدنویسی نشده‌اند.

## Current high-value unknowns

### U-001
آیا یکی از P/S/T implementationها در یک task واقعی به‌طور پایدار بر دیگری برتری دارد، یا تفاوت آنها عمدتاً ناشی از initial conditions و thresholds است؟

### U-002
آیا cognitive bias واقعاً predictive value افزوده دارد، یا فقط forecast را به‌صورت heuristic جابه‌جا می‌کند؟

### U-003
آیا phase labels دارای predictive/decision value مستقل هستند یا صرفاً بازتوصیف state هستند؟

### U-004
آیا replay stability در حضور non-determinism، time، external market feeds و model version drift حفظ می‌شود؟

### U-005
آیا evidence aggregation می‌تواند در common-mode failure شکست بخورد بدون اینکه confidence ظاهراً کاهش یابد؟

### U-006
آیا LUMEN state transfer واقعاً انتقال state است یا بازسازی narrative از روی context؟

### U-007
آیا Unknown-Space Explorer می‌تواند artifact یا behavior جدیدی کشف کند که از قبل به‌صورت rule یا template در آن تعبیه نشده باشد؟

### U-008
آیا amplitude-dependent restoring force در سیستم مورد مطالعه واقعاً وجود دارد یا نتیجه selection، normalization یا model misspecification است؟

### U-009
کدام metricها در HHJ-CSG واقعاً با outcome safety مرتبط‌اند و کدام صرفاً proxy هستند؟

### U-010
حداقل evidence لازم برای انتقال یک prototype به canonical production path چیست؟

## Discovery rule
هر unknown باید در صورت امکان به hypothesis قابل ابطال تبدیل شود. اگر تبدیل آن فعلاً ممکن نیست، باید دلیل آن ثبت شود.
