# Scenario ROI Calculator

This calculator produces a scenario, not a prediction or guarantee.

## Formula
- traditionalValue = baselineCost × traditionalMultiplier
- modeledValue = baselineCost × cognitiveMultiplier ÷ timeCompression
- modeledAdvantage = modeledValue / traditionalValue − 1

## Example
Inputs from the earlier proposal:
- baselineCost = 50,000
- traditionalMultiplier = 1.2
- cognitiveMultiplier = 3.7
- timeCompression = 0.6

Results:
- traditionalValue = 60,000
- modeledValue ≈ 308,333.33
- modeledAdvantage ≈ 413.89%

The previously stated 208% improvement does not follow from those displayed inputs. This repository records the arithmetic correction explicitly rather than silently preserving an inconsistent claim.
