# 90-Day Commercial Plan

## Objective

Convert Action Gate from an engineering artifact into the first paid customer deployment.

## Days 1–14: sharpen the offer

1. Publish the product-first README.
2. Package the one-tool pilot.
3. Prepare a 12-minute demo.
4. Prepare one technical evidence report.
5. Build a list of 50 target organizations.
6. Identify one security/platform contact and one technical champion per account.
7. Lead with runtime authorization, not "AI safety."

## Days 15–45: direct outreach

Weekly target:
- 50 highly targeted accounts researched;
- 20 personalized first contacts;
- 10 technical conversations requested;
- 3 live demos;
- 1 pilot proposal.

Prioritize organizations already giving agents write access to production systems, APIs, databases, cloud resources or MCP tools.

## Days 46–75: paid pilots

Run pilots against one real tool.

Do not broaden scope before the first acceptance test passes.

Capture:
- baseline architecture;
- blocked bypass attempts;
- replay results;
- action/tenant binding results;
- latency;
- operational effort;
- customer-stated value.

Turn the evidence into the next sales artifact.

## Days 76–90: convert and repeat

Convert the successful pilot into SELF_HOSTED, MANAGED or ENTERPRISE.

Ask for a second protected tool only after the first is accepted.

Build the second case study around measurable operational impact rather than feature count.

## Sales discipline

Never promise:
- universal AI safety;
- perfect prevention of prompt injection;
- regulatory certification;
- downstream correctness;
- zero business risk.

Promise only what the customer's acceptance test demonstrates.
