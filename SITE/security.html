Security boundary

Action Gate is positioned as an enforcement boundary immediately before a protected action executes.

  • Authorization decision is bound to execution context.
  • Single-use execution authorization limits reuse of an approved action.
  • Evidence is retained for the agreed execution path.
  • Required authorization/evidence failures are designed to fail closed.
  • HTTP and MCP execution paths are supported by the commercial architecture.

Security claims are limited to documented product behavior and agreed deployment scope. No universal safety or regulatory-compliance claim is made.
